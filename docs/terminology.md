# Studio 용어와 도메인 경계

이 문서는 Studio의 사용자 화면, API 설명, 에이전트 도구가 사용하는 용어의 기준이다.
일반적인 음악 파일 묶음이나 편집기 저장 파일을 무조건 프로젝트라고 부르지 않는다.

| 용어 | 정의 | 다른 개념과의 관계 |
| --- | --- | --- |
| 곡 · Song | 프로젝트와 채보의 배경음으로 사용하는 음악과 그 식별 정보 | 하나의 곡을 여러 프로젝트와 채보에서 사용할 수 있다. 곡 자체는 생성 규칙이나 노트 배열이 아니다. |
| 프로젝트 · Project | 채보를 생성하기 위한 규칙과 구성요소의 모음 | 사용할 곡과 Single/Double 모드를 명시하고, 생성에 사용하는 규칙을 편집·저장한다. 프로젝트와 생성된 결과물은 구분한다. |
| 채보 · Chart | 프로젝트에서 생성한 결과물인 개별 노트 구성 | 탭·동시 입력·홀드의 위치와 길이를 가진다. 프로젝트의 규칙을 바꿔도 이미 생성된 채보를 소급해서 변경하지 않는다. |
| 라이브러리 · Library | 여러 프로젝트에서 공유할 수 있도록 재사용 가능하게 만든 구성요소의 모음 | 프로젝트의 구성요소를 라이브러리에 공개하고 다른 프로젝트에서 가져와 재사용한다. 단순한 곡·채보 파일 목록의 동의어가 아니다. |

외부 UCS나 예전 편집 파일에서 가져온 채보도 결과물로 보관할 수 있다. 그 노트 배열에서
원래 생성 규칙을 알아냈다고 주장하거나, 없는 프로젝트 이력을 만들어 붙이지 않는다.
기존 `project.json`/`StudioProjectV1`이라는 저장 형식 이름은 호환용 **채보 문서**를 뜻하며,
위에서 정의한 생성 규칙 프로젝트와 구분한다.

## 관계

```text
곡: 배경음 ───────────────┐
                         ▼
라이브러리 구성요소 ──→ 프로젝트: 모드 + 생성 규칙 ──→ 채보 A
                         │                       └─→ 채보 B
                         └─ 구성요소를 재사용 가능하게 만들기 ──→ 라이브러리
```

## 모드

- Single은 한 패드의 다섯 레인, Double은 두 패드의 열 레인을 사용한다.
- 모드는 프로젝트를 만들 때 반드시 선택한다. 생성된 채보는 그 모드를 따른다.
- Single/Double은 단순한 UCS 내보내기 옵션이 아니라 생성·편집·저장·검증의 제약이다.
- 모드가 다른 결과물을 만들려면 해당 모드의 프로젝트를 사용한다. 기존 노트를 조용히
  잘라 내거나, 모드를 바꾸는 것만으로 다른 형식으로 변환됐다고 간주하지 않는다.

## 에이전트의 작업 대상

에이전트가 프로젝트를 읽는다는 것은 실제 저장된 생성 규칙과 구성요소를 읽는 것이다.
프로젝트를 쓴다는 것은 검증과 리비전 충돌 검사를 거쳐 그 규칙을 저장하는 것이다.
채보 제안만 생성하거나 자연어로 변경했다고 말하는 것은 프로젝트 쓰기가 아니다.

곡의 음원 파일, 원본 ZIP, 채보 결과물, 프로젝트 규칙, 라이브러리 구성요소는 서로
다른 자원이다. 프로젝트 쓰기 권한은 임의 파일 시스템·셸·자격 증명 접근 권한을 뜻하지 않는다.

## 편집 좌표와 타이밍

- 박자 위치와 홀드 길이는 기약분수로 표현한다. BPM을 바꾸어도 노트의 박자 위치와
  길이는 바뀌지 않으며, 실제 음원 시간으로의 변환만 달라진다.
- 편집 화면의 **split**은 앞으로 배치할 노트의 박당 분할 수다. split 3의 1/3박자 노트와
  split 4의 1/4박자 노트가 같은 마디 안에 함께 존재할 수 있다. split 변경은 이미 저장한
  좌표를 바꾸지 않으며, UCS로 출력할 때만 공통 Split 12 격자를 만든다.
- global tick은 편집 원본의 시간 단위가 아니다. 기존 파일을 가져올 때는 박자 분수로
  정확히 변환하고, native 평가·생성 및 출력 형식의 경계에서만 필요한 좌표를 만든다.
  표현할 수 없는 좌표를 반올림하여 저장하거나 출력하지 않는다.
- **자동 길이**는 마지막 노트의 점유 칸과 홀드 끝, 자동 생성 구간으로 정한다.
  **명시 길이**는 자동으로 이동하는 종료선을 누르거나 드래그하여 고정한 끝 경계다.
  텍스트 입력은 없으며 이미 배치한 내용을 잘라 낼 수 없다.
  출력 형식에 필요한 마지막 빈 줄은 원본의 명시 길이나 노트로 되돌려 저장하지 않는다.
- **노트 조각**은 여러 노트의 상대 박자 위치와 길이를 함께 보관한 라이브러리 구성요소다.
  적용할 때 기준 박자에 더하여 배치하며, 다른 BPM에서도 상대 리듬을 유지한다.
- **채보 아티스트**는 채보 작성자다. 곡의 가수·아티스트 정보와 구분하며, 곡 아티스트를
  자동으로 복사하여 채보 작성자로 표시하지 않는다.
- **기본 UCS**는 프로젝트 생성 시 명시적으로 선택하는 타이밍 원본이다. 선택된 원본의
  타이밍을 복사하는 것이며, 그 노트에서 생성 규칙이나 작성자를 추정하는 것이 아니다.
